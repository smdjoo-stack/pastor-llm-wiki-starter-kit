# 설교위키 안내

설교위키는 설교문을 쌓아두는 곳이 아니라 다음 설교에서 다시 꺼내 쓸 작은 지식을 저장하는 곳입니다.

| 폴더 | 담는 내용 | 예시 |
|---|---|---|
| 21. 성경본문 | 본문별 관찰과 반복 통찰 | 사도행전 18장 |
| 22. 설교주제 | 목회적 주제 | 두려움, 공동체 |
| 23. 성경인물 | 인물의 상황·반응·변화 | 바울, 다윗 |
| 24. 신학 | 신학 개념과 목회적 의미 | 하나님의 임재 |
| 25. 예화 | 사실 확인 가능한 이야기 | 계획과 현실 |
| 26. 인용문 | 출처가 확인된 짧은 인용 | 저자 - 핵심 문장 |
| 27. 묵상과통찰 | 재사용할 수 있는 생각 | 두려움과 통제 |
| 28. 설교아이디어 | 아직 설교가 되지 않은 씨앗 | 혼자일 때 보내시는 사람 |
| 29. MOC | 여러 지식을 연결한 연구 지도 | 두려움 MOC |

## 좋은 Wiki의 기준

- 한 노트가 한 가지 질문 또는 개념에 집중한다.
- 제목만 보아도 어떤 통찰인지 알 수 있다.
- 원본 링크가 있어 근거를 확인할 수 있다.
- 관련 링크마다 가능하면 관계가 설명되어 있다.
- 새 내용을 덧붙일 때 기존 내용과 구분되고 갱신일이 남는다.

## 중복을 줄이는 방법

새 노트를 만들기 전에 제목, 별칭, 비슷한 문장을 검색합니다. `불안`과 `염려`처럼 가까운 말은 무조건 합치지 말고 차이를 설명하거나 서로 연결합니다.
