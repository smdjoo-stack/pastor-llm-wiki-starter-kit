# /질문

## 실행 전 필수로 읽기

1. `LLM-운영지침.md`
2. `90. 설정/명령어/질문.md` — 이 명령의 상세 검색 순서와 출력 형식

위 두 문서의 규칙을 그대로 따른다. **Wiki 노트나 MOC를 새로 만들지 않는다.**

## 대상

$ARGUMENTS

질문이 모호하면 무엇을 궁금해하는지 짧게 확인한다.

## 완료 후

- `90. 설정/명령어/질문.md`의 "완료 보고" 항목대로 요약한다.
- `log.md` 맨 위에 새 항목을 추가한다: `## [YYYY-MM-DD] /질문 | {질문 요약}`
