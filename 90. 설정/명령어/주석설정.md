# /주석설정

## 목적

`/주석`이 본문 리서치를 만들 때 따르는 규칙(`90. 설정/출력레시피/주석.md`)을 목회자의 필요에 맞게 조정한다. 처음 한 번 또는 필요할 때 실행한다.

## 방법 A: 질문으로 설정

한꺼번에 많은 질문을 하지 말고 다음 중 필요한 항목을 5~7개 이내로 묻는다.

- 리서치 깊이는 어느 정도가 적당한가 (간단 참고 vs 상세 학술적)?
- 원어 노트는 얼마나 다루길 원하는가?
- 선호하는 주석서·신학 전통·자료가 있는가?
- 반드시 포함할 항목(예: 항상 구조 분석 포함)이 있는가?
- 피하고 싶은 것(예: 특정 신학적 논쟁 다루지 않기)이 있는가?

답변을 요약해 사용자에게 확인받은 뒤 `90. 설정/출력레시피/주석.md`를 수정한다.

## 방법 B: 기존 좋은 예시로 설정

1. 사용자가 만족했던 과거 주석 문서나 외부 예시가 있으면 참고한다.
2. 반복되는 깊이, 구조, 다루는 항목, 문체를 분석한다.
3. 예시의 구체적 내용은 복제하지 않고 규칙만 추출한다.
4. 기존 레시피와 충돌하는 변경은 먼저 보여주고 확인받는다.
5. 확정 후 `90. 설정/출력레시피/주석.md`를 갱신하고 "변경 기록"에 날짜와 변경 내용을 추가한다.
