# /상태

## 목적

지금 볼트가 어떤 상태인지 한눈에 보여주는 읽기 전용 스냅샷. 파일을 만들거나 고치지 않는다.

## 입력

없음. 있다면 특정 폴더(예: `00. 수집함`)로 범위를 좁힐 수 있다.

## 실행

1. 각 폴더의 파일 개수를 센다 (`.gitkeep` 제외, 파일명에 "안내"가 들어간 문서와 `종류`/`상태`가 "예시"인 파일도 제외 — 실제 콘텐츠만 센다).
   - `10. 원본자료`, `20. 설교위키`(하위 8개 분류별), `29. MOC`, `30. 설교준비/완성설교`, `70. 설교활용`
2. `00. 수집함`에 대기 중인 파일을 폴더별로 나열하고, 오래 남아 있는 파일(예: 2주 이상)이 있으면 표시한다.
3. `log.md`에서 가장 최근 활동 5~10건을 요약한다.
4. `index.md`의 통계표와 실제 폴더 개수가 다르면 "동기화 필요"로 표시한다 (수정은 하지 않음).
5. `90. 설정/대시보드.html`의 `DATA.updated`가 `index.md`의 `갱신일`과 다르면 역시 "동기화 필요"로 표시한다 (수정은 하지 않음 — 갱신은 `/수집`·`/위키`·`/설교완성`이 한다).

## 완료 보고

다음을 표 형태로 보여준다.

- 폴더별 개수
- 수집함 대기 목록과 오래 남은 항목
- 최근 활동 요약
- `index.md`, `90. 설정/대시보드.html`과의 불일치 여부 (있다면 `/점검` 또는 해당 명령 재실행을 제안)
