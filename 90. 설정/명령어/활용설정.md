# /활용설정

## 목적

기본 출력 레시피를 우리 교회의 대상, 분량, 문체, 구성에 맞게 안전하게 조정한다. 처음 한 번 또는 필요할 때 실행한다.

## 방법 A: 질문으로 설정

한꺼번에 많은 질문을 하지 말고 다음 중 필요한 항목을 5~7개 이내로 묻는다.

- 어떤 결과물을 설정할 것인가?
- 주 사용자는 누구인가?
- 원하는 분량 또는 시간은?
- 문체와 난이도는?
- 반드시 포함할 구성은?
- 피하고 싶은 표현은?
- 질문·적용·기도의 비중은?

답변을 요약해 사용자에게 확인받은 뒤 해당 레시피를 수정한다.

## 방법 B: 기존 좋은 예시로 설정

1. 사용자가 준 예시를 해당 `90. 설정/출력예시` 폴더에 보존한다.
2. 여러 예시에서 반복되는 분량, 구조, 문체, 질문 수, 성경 표시, 적용 방식을 분석한다.
3. 예시의 내용은 복제하지 않고 규칙만 추출한다.
4. 기존 레시피와 충돌하는 변경을 먼저 보여주고 확인받는다.
5. 확정 후 해당 `출력레시피`를 갱신하고 변경 기록을 남긴다.
