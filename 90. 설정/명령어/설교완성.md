# /설교완성

## 목적

목회자가 확정한 설교를 완성본으로 보존하고, 이 설교에서 새로 생긴 재사용 지식을 Wiki와 MOC에 반영한다.

## 실행 전 확인

- 어떤 파일이 목회자가 확정한 최종본인지 확인한다.
- 1차설교와 연결자료를 AI가 임의로 합쳐 최종본으로 만들지 않는다.

## 실행

1. 확정본을 `30. 설교준비/완성설교`에 날짜와 제목으로 저장한다.
2. 제목, 날짜, 본문, 핵심 메시지, 시리즈, 대상, 절기 메타데이터를 확인한다 (`90. 설정/사용안내/07. 속성 작성 규칙.md`의 날짜·본문·절기 표기 규칙을 따른다).
3. 기존 Wiki에서 이미 다룬 내용과 이번 설교에서 새로 발전한 내용을 구분한다.
4. 재사용 가치가 있는 새 통찰만 Wiki로 만들거나 기존 Wiki에 덧붙인다. 새로 만들거나 내용이
   갱신된 모든 Wiki의 `출처` 배열에 이 완성설교를 중복 없이 추가한다
   (`07. 속성 작성 규칙` 11번).
5. 관련 본문·주제·인물·신학 Wiki와 MOC를 갱신한다.
6. 완성설교의 `관련본문`·`관련주제`·`관련인물`·`관련신학`·`관련예화`·`관련인용` 프론트매터 배열을 채운다 (위키링크는 큰따옴표로 감싼다, 예: `"[[다윗]]"`). 본문(body)에도 같은 링크를 사람이 읽을 문장으로 남긴다 — 프론트매터와 본문 링크는 서로 대체하지 않는다.
7. `index.md`의 "설교 흐름" 표에 새 행을 추가한다: 날짜·제목·본문·절기·시리즈 (최신 항목이 위로 오도록).
8. 초안과 연결자료는 기록으로 그대로 둔다.

## 완료 조건

- 완성설교의 위치가 명확하다.
- 원본 의미와 문체가 보존되었다.
- 중복 Wiki가 생기지 않았다.
- Wiki에서 완성설교로 근거를 되짚을 수 있다.

## 태그 (`07. 속성 작성 규칙` 13번)

만들거나 갱신하는 모든 노트의 `태그`를 통제 어휘로 채운다. 자유 주제어는 쓰지 않는다.

- `본문/{정식 책 이름}/{장}` — 예: `본문/요한복음/15장`, `본문/시편/63편`. 절은 넣지 않는다. 줄임말 금지. **설교주제·성경인물·신학은 상한이 없다**(허브 노트라 계속 자라는 것이 정상). **그 밖은 6개**(규칙 13-1). 상한 대신 근거 규칙이 품질을 지킨다 — **장을 붙이려면 그 장이 노트 본문에 실제로 인용돼 있어야 한다.** 근거가 없으면 장을 떼고 책 단위로 둔다.
- `용도/{상황}` — 장례·결혼·심방·새가족·다음세대·가정·재정·직장·공동체·수련회 중 **그 상황에서 실제로 꺼내 쓸 수 있을 때만**. 단어가 나온다고 붙이지 않는다.
- `절기/{표준값}` — 7번의 표준값에 해당할 때만.
- `검증/원어미대조` · `검증/사실미대조` · `검증/출처미확인` · `검증/날짜미상` · `검증/제목미확정` · `검증/원고미완성`
  — 본문에 `> [!question] 확인 필요` 콜아웃을 남겼으면 **그에 대응하는 검증 태그를 반드시 함께 붙인다.**
  콜아웃만 있고 태그가 없으면 나중에 검색되지 않는다.
- `상충` — `> [!warning] 상충하는 정보` 콜아웃을 남겼으면 붙인다.

기존 노트를 갱신할 때는 **태그를 덮어쓰지 말고 없는 것만 더한다.** `검증/*`과 `상충`은
AI가 스스로 지우지 않는다 — 목회자가 확인한 뒤에만 지운다.
