# /설교완성

## 목적

목회자가 확정한 설교를 완성본으로 보존하고, 이 설교에서 새로 생긴 재사용 지식을 Wiki와 MOC에 반영한다.

## 실행 전 확인

- 어떤 파일이 목회자가 확정한 최종본인지 확인한다.
- 1차설교와 연결자료를 AI가 임의로 합쳐 최종본으로 만들지 않는다.

## 실행

1. 확정본을 `30. 설교준비/완성설교`에 날짜와 제목으로 저장한다.
2. 제목, 날짜, 본문, 핵심 메시지, 시리즈, 대상 메타데이터를 확인한다.
3. 기존 Wiki에서 이미 다룬 내용과 이번 설교에서 새로 발전한 내용을 구분한다.
4. 재사용 가치가 있는 새 통찰만 Wiki로 만들거나 기존 Wiki에 덧붙인다.
5. 관련 본문·주제·인물·신학 Wiki와 MOC를 갱신한다.
6. 완성설교에 관련 Wiki/MOC 링크를 남긴다.
7. 초안과 연결자료는 기록으로 그대로 둔다.

## 완료 조건

- 완성설교의 위치가 명확하다.
- 원본 의미와 문체가 보존되었다.
- 중복 Wiki가 생기지 않았다.
- Wiki에서 완성설교로 근거를 되짚을 수 있다.
