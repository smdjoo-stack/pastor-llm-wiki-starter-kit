# /설교완성

## 목적

목회자가 확정한 설교를 완성본으로 보존하고, 이 설교에서 새로 생긴 재사용 지식을 Wiki와 MOC에 반영한다.

## 실행 전 확인

- 어떤 파일이 목회자가 확정한 최종본인지 확인한다.
- 1차설교와 연결자료를 AI가 임의로 합쳐 최종본으로 만들지 않는다.

## 실행

1. 확정본을 `30. 설교준비/완성설교`에 날짜와 제목으로 저장한다.
2. 제목, 날짜, 본문, 핵심 메시지, 시리즈, 대상, 절기 메타데이터를 확인한다 (`90. 설정/사용안내/07. 속성 작성 규칙.md`의 날짜·본문·절기 표기 규칙을 따른다).
3. 기존 Wiki에서 이미 다룬 내용과 이번 설교에서 새로 발전한 내용을 구분한다.
4. 재사용 가치가 있는 새 통찰만 Wiki로 만들거나 기존 Wiki에 덧붙인다. 새로 만들거나 내용이
   갱신된 모든 Wiki의 `출처` 배열에 이 완성설교를 중복 없이 추가한다
   (`07. 속성 작성 규칙` 11번).
5. 관련 본문·주제·인물·신학 Wiki와 MOC를 갱신한다.
6. 완성설교의 `관련본문`·`관련주제`·`관련인물`·`관련신학`·`관련예화`·`관련인용` 프론트매터 배열을 채운다 (위키링크는 큰따옴표로 감싼다, 예: `"[[다윗]]"`). 본문(body)에도 같은 링크를 사람이 읽을 문장으로 남긴다 — 프론트매터와 본문 링크는 서로 대체하지 않는다.
7. `index.md`의 "설교 흐름" 표에 새 행을 추가한다: 날짜·제목·본문·절기·시리즈 (최신 항목이 위로 오도록).
8. 초안과 연결자료는 기록으로 그대로 둔다.

## 완료 조건

- 완성설교의 위치가 명확하다.
- 원본 의미와 문체가 보존되었다.
- 중복 Wiki가 생기지 않았다.
- Wiki에서 완성설교로 근거를 되짚을 수 있다.
