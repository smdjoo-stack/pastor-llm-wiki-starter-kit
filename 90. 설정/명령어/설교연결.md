# /설교연결

## 목적

목회자가 쓴 1차설교를 바꾸지 않고, 그 설교의 질문에 답할 만한 기존 지식을 찾아 별도의 `연결자료`로 제안한다.

## 입력

`30. 설교준비/1차설교`의 원고와, 가능하면 설교자가 지금 씨름하는 한 문장의 질문.

## 검색 순서

1. 초안에서 본문·주제·인물·신학·청중·핵심 질문을 추출한다.
2. `30. 설교준비/주석`에 같은 본문의 주석이 있는지 확인한다. 있으면 참고하되, `검토: 미검토` 상태면 "AI 리서치 — 검증 필요"로 표시하고 원문을 요약하지 않고 관련 구간을 그대로 인용한다.
3. 제목과 정확한 개념의 직접 일치를 찾는다.
4. 관련 MOC를 읽어 인접 본문과 주제로 확장한다.
5. 전체 Wiki에서 MOC에 아직 연결되지 않은 자료를 찾는다.
6. 중요한 인용이나 문맥은 원본자료에서 확인한다.
7. 관련도, 근거 신뢰도, 새로움, 설교자의 기존 반복 사용 여부를 평가한다.

## 출력

`90. 설정/템플릿/연결자료 템플릿.md`를 사용해 `30. 설교준비/연결자료`에 새 파일을 만든다.

연결자료에는 다음을 구분한다.

- 반드시 검토할 강한 연결
- 선택적으로 검토할 보조 연결
- 이전 설교와 반복될 수 있는 지점
- 사실·출처·신학 확인이 필요한 지점
- 설교자가 결정할 질문

## 금지

- 1차설교 파일을 직접 수정하지 않는다.
- 연결 이유 없이 링크만 길게 나열하지 않는다.
- 자료가 없는데도 그럴듯한 인용이나 예화를 만들어내지 않는다.
- AI가 최종 설교 방향을 결정하지 않는다.
