# /활용

## 목적

완성설교 한 편을 선택한 채널에 맞는 파생 콘텐츠로 만든다.

## 먼저 확인할 것

1. 대상 완성설교
2. 만들 결과: 소그룹 나눔, 주보 에세이, 카드뉴스, 숏츠, SNS, 또는 모두
3. 이번 요청의 특별 조건: 대상, 분량, 일정, 플랫폼

사용자가 선택하지 않았다면 한 번에 필요한 선택만 짧게 묻는다.

## 자료 우선순위

1. 사용자의 이번 요청
2. 현재 완성설교
3. 해당 `출력레시피`
4. 해당 `출력예시`의 형식과 문체
5. 공통 운영지침

좋은 예시의 내용은 복사하지 않고 구조·분량·문체·질문 방식만 참고한다.

## 저장

각 결과를 `70. 설교활용`의 해당 폴더에 `날짜 설교제목 - 결과종류.md`로 저장한다.

## 금지

- 설교자가 말하지 않은 신학적 주장을 추가하지 않는다.
- 성경 구절이나 실제 사례를 임의로 덧붙이지 않는다.
- 활용 결과를 `20. 설교위키`에 다시 넣지 않는다.
