# 명령어 사용법

이 볼트의 `/수집` 같은 표현은 특정 앱에 종속된 버튼이 아니라 AI와 함께 사용하는 약속된 요청어입니다. 명령만 입력해도 되지만 대상과 원하는 결과를 함께 말하면 더 정확합니다.

## 좋은 요청 예시

```text
/수집
00. 수집함/책에 오늘 넣은 파일만 처리해 줘.
원본은 보존하고 새 Wiki를 만들기 전에 중복부터 확인해 줘.
```

```text
/설교
2026-09-13 두려워하지 말라.md를 대상으로 해 줘.
핵심 질문은 “두려움 가운데 하나님은 어떻게 공동체를 주시는가?”야.
```

## 공통 실행 방식

1. AI는 `LLM-운영지침.md`와 해당 명령 파일을 읽습니다.
2. 대상이 모호하면 파일 목록을 보여주고 짧게 확인합니다.
3. 기존 파일을 검색하고 새 파일·수정 파일 계획을 알립니다.
4. 작업 후 생성·수정·보류·확인 필요 항목을 보고합니다.

사용자가 `미리보기만` 또는 `파일은 수정하지 마`라고 하면 제안만 하고 변경하지 않습니다.
