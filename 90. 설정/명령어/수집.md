# /수집

## 목적

`00. 수집함`의 새 자료를 원본으로 보존하고, 다음 설교에서 다시 쓸 가치가 있는 지식을 Wiki로 추출하여 관련 MOC에 연결한다. 단순 요약으로 끝내지 않는다.

## 입력

- 대상 파일 또는 수집함 폴더
- 선택 사항: 이번에 관심 있는 질문, 주제, 본문

## 실행

1. 대상과 자료 종류를 확인한다.
2. 같은 원본이 이미 `10. 원본자료`에 있는지 확인한다.
3. 원문을 내용 변경 없이 해당 원본 폴더로 이동하거나 복사한다. 이동 여부가 불분명하면 복사를 우선하고 사용자에게 알린다. 이때 `90. 설정/템플릿/원본자료 템플릿.md`의 프론트매터 형식(`종류`/`자료유형`/`제목`/`저자_발행자`/`출처_URL`/`발행일`/`확인일`/`상태`)을 씌운다 — 수집함에 있던 원문은 프론트매터가 없어도 되지만, `10. 원본자료`로 넘어가는 순간부터는 이 형식을 갖춰야 한다.
4. 3번의 프론트매터 값(출처·저자·URL·발행일·확인일·페이지/시간)을 가능한 범위에서 채운다. 날짜 형식과 `상태` 값은 `90. 설정/사용안내/07. 속성 작성 규칙.md`를 따른다(`상태: 미처리` → Wiki 추출을 마치면 `처리완료`). 본문의 원문 내용 자체는 손대지 않는다. 논지가 있는 자료(책·강연·논문 등)는 `## 논지 요약`의 핵심 주장·주요 논거를 채운다 — 원문을 대체하지 않는 별도 섹션이다.
5. 자료를 다음 설교에서 다시 사용할 수 있는 작은 단위로 읽는다.
6. 기존 Wiki와 제목·동의어·내용 중복을 검색한다.
7. 새 Wiki를 만들거나 기존 Wiki에 근거 있는 내용을 덧붙인다. Wiki 프론트매터의 `출처` 배열에 3번에서 보존한 원본 노트 위키링크를 큰따옴표로 감싸 넣는다 (`90. 설정/사용안내/07. 속성 작성 규칙.md` 11번). 기존 Wiki에 덧붙일 때는 배열에 더한다.
8. 관련 MOC가 있으면 연결한다. 없고 자료가 아직 적으면 새 MOC를 만들지 않는다.
9. 원본 노트에 생성·수정한 Wiki의 링크를 남긴다. 원문 자체는 변경하지 않고 메타데이터나 별도 `처리 기록`만 추가한다.

## 추출 후보

성경본문, 설교주제, 성경인물, 신학, 예화, 인용문, 묵상과통찰, 설교아이디어. 모든 후보를 억지로 만들지 말고 재사용 가치가 있는 것만 만든다.


## 성경본문 Wiki의 연결 필드 (`07. 속성 작성 규칙` 6-1번)

`성경본문` Wiki를 만들거나 갱신하면 `관련본문`·`관련주제`·`관련인물`·`관련신학`·`관련예화`·`관련인용`·`관련통찰` 배열을 채운다. 본문(body)의 `## 관련 주제·인물·신학`·`## 관련 통찰과 예화` 절에 적은 링크를 그대로 올리면 된다 — 본문 링크는 사람이 읽는 설명이고 배열은 기계가 집계하는 색인이라 **둘 다 남긴다.** 실제로 존재하는 노트만 넣고, MOC·설교아이디어·원본자료 링크는 넣지 않는다.

## 태그 (`07. 속성 작성 규칙` 13번)

만들거나 갱신하는 모든 노트의 `태그`를 통제 어휘로 채운다. 자유 주제어는 쓰지 않는다.

- `본문/{정식 책 이름}/{장}` — 예: `본문/요한복음/15장`, `본문/시편/63편`. 절은 넣지 않는다. 줄임말 금지. **설교주제·성경인물·신학은 상한이 없다**(허브 노트라 계속 자라는 것이 정상). **그 밖은 6개**(규칙 13-1). 상한 대신 근거 규칙이 품질을 지킨다 — **장을 붙이려면 그 장이 노트 본문에 실제로 인용돼 있어야 한다.** 근거가 없으면 장을 떼고 책 단위로 둔다.
- `용도/{상황}` — 장례·결혼·심방·새가족·다음세대·가정·재정·직장·공동체·수련회 중 **그 상황에서 실제로 꺼내 쓸 수 있을 때만**. 단어가 나온다고 붙이지 않는다.
- `절기/{표준값}` — 7번의 표준값에 해당할 때만.
- `검증/원어미대조` · `검증/사실미대조` · `검증/출처미확인` · `검증/날짜미상` · `검증/제목미확정` · `검증/원고미완성`
  — 본문에 `> [!question] 확인 필요` 콜아웃을 남겼으면 **그에 대응하는 검증 태그를 반드시 함께 붙인다.**
  콜아웃만 있고 태그가 없으면 나중에 검색되지 않는다.
- `상충` — `> [!warning] 상충하는 정보` 콜아웃을 남겼으면 붙인다.

기존 노트를 갱신할 때는 **태그를 덮어쓰지 말고 없는 것만 더한다.** `검증/*`과 `상충`은
AI가 스스로 지우지 않는다 — 목회자가 확인한 뒤에만 지운다.

## 완료 보고

- 보존한 원본
- 새로 만든 Wiki
- 갱신한 Wiki와 MOC
- 중복 때문에 만들지 않은 항목
- 출처 확인이 필요한 항목
