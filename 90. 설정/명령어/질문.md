# /질문

## 목적

특정 설교 준비와 무관하게, 지금까지 쌓인 설교위키에 자유 질문을 던져 답을 찾는다. `/설교연결`과 달리 입력이 1차설교 파일이 아니라 질문 그 자체다.

## 입력

- 자유 질문 한 문장 (예: "두려움과 믿음의 관계에 대해 내가 만든 위키가 뭐라고 하지?")

## 검색 순서

1. 질문에서 본문·주제·인물·신학 등 핵심 키워드를 추출한다.
2. `30. 설교준비/주석`에 관련 본문의 AI 리서치가 있는지 확인한다. 있으면 참고하되 `검토: 미검토`면 "AI 리서치 — 검증 필요"로 표시한다.
3. 제목·별칭·정확한 문구로 직접 일치 항목을 찾는다.
4. 관련 MOC를 읽어 탐색 범위를 넓힌다.
5. 전체 설교위키에서 MOC에 아직 연결되지 않은 관련 노트를 찾는다.
6. 필요한 경우에만 원본자료로 돌아가 문맥과 출처를 확인한다.
7. 찾은 근거를 종합해 답변을 구성한다. 근거가 없는 부분은 답을 지어내지 않고 "확인 필요"로 남긴다.

## 출력

`90. 설정/템플릿/질문 템플릿.md`를 사용해 `50. 질문`에 새 파일을 만든다. 파일명: `YYYY-MM-DD Q-{질문 요약}.md`.

## 모순 발견 시

답변을 구성하다 기존 Wiki 노트끼리 상충하는 내용을 발견하면, 새 노트를 만들지 않고 해당 노트들에 `> [!warning] 상충하는 정보` 콜아웃만 추가한다. 이 경우 완료 보고에 어떤 노트를 건드렸는지 명시한다.

## 금지

- 근거 없는 답을 만들어내지 않는다.
- Wiki 노트를 새로 만들거나 MOC를 새로 만들지 않는다 (그건 `/수집`·`/등록`의 역할이다).
- 1차설교나 완성설교 파일을 건드리지 않는다.

## 완료 보고

- 질문과 저장 위치
- 답변 요약
- 근거로 쓴 Wiki/MOC/주석 목록
- 확인 필요로 남긴 항목
- 모순을 발견해 콜아웃을 추가한 노트가 있으면 목록
