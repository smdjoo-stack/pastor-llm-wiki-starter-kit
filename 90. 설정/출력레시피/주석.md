# 본문 주석 제작 규칙

## 대상과 목적

- 대상: 설교를 준비하는 목회자 본인 (외부 공개용 아님)
- 목적: 설교 원고를 쓰기 전에 참고할 본문 배경 지식을 정리한다. 설교 방향을 대신 정하지 않는다.

## 다룰 범위 (기본값)

- 본문과 문맥
- 원어 노트 (핵심 단어 1~3개 정도, 과도한 원어 나열 지양)
- 역사적·문화적 배경
- 구조 분석
- 주요 해석상 쟁점 (있는 경우만)

## 깊이

- 설교자 본인이 읽을 참고자료 수준 — 각주식 학술 논증보다 "설교에 실제로 쓸 수 있는 요약"에 무게를 둔다.
- 원어 분석은 설교에 적용 가능한 단어 위주로 제한한다. 모든 단어를 다 풀이하지 않는다.

## 신학적 입장

- 특정 교단·신학 전통을 기본으로 강요하지 않는다. 해석이 갈리는 지점은 "주요 해석상 쟁점"에 복수 관점을 나열한다.

## 우선 참고자료

- (아직 지정된 선호 주석서·자료 없음 — `/주석설정`으로 추가 가능)

## 피할 것

- 확인되지 않은 원어 어원 설명을 단정적으로 제시하지 않는다 (`해석 제안`으로 표시).
- 존재하지 않는 학자·주석서를 인용하지 않는다.
- 설교의 결론이나 적용을 대신 정하지 않는다 — 참고 자료로 그친다.

## 출력 점검

- 목회자가 이 문서만 보고 설교 방향을 스스로 판단할 수 있는가?
- 원어·역사적 사실 중 확인이 필요한 부분이 명확히 표시되어 있는가?
