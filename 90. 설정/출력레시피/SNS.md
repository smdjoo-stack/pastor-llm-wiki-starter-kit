# SNS 게시물 제작 규칙

## 기본 목적

설교의 핵심 메시지 하나를 모바일에서 쉽게 읽고, 자신의 삶과 연결할 수 있게 전한다.

## 기본 형식

- 플랫폼을 지정하지 않으면 범용 게시물 1개를 만든다.
- 첫 1~2문장에 공감되는 장면이나 질문을 둔다.
- 본문은 짧은 문단으로 나누고 한 메시지에 집중한다.
- 마지막에는 적용 질문 또는 기억 문장 하나를 둔다.
- 해시태그는 3~5개 이내로, 실제 내용과 직접 관련된 것만 제안한다.

## 원칙

- 과장된 약속, 공포, 클릭 유도 표현을 피한다.
- 성경 구절은 번역과 절을 확인한다.
- 설교자나 교회의 평소 어조를 우선한다.
- 플랫폼 글자 수나 링크 정책이 지정되면 이번 요청을 우선한다.

## 선택 출력

사용자가 원하면 다음을 함께 만든다.

- 짧은 버전
- 긴 버전
- 이미지 위에 넣을 한 문장
- 댓글 대화를 여는 질문
