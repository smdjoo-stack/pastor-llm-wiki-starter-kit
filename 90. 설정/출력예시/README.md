# 출력예시 사용법

우리 교회에서 이미 잘 사용한 결과물을 종류별 폴더에 넣습니다.

권장 수량은 종류마다 3~5개입니다. 이름은 `좋은예시 01 - 제목.md`처럼 적습니다. 개인정보, 연락처, 상담 사례는 먼저 삭제하거나 익명화합니다.

그 뒤 AI에게 다음처럼 요청합니다.

```text
/활용설정
출력예시/주보에세이의 파일들을 비교해서
공통된 분량, 구성, 문체, 성경표시, 마지막 문장 방식을 찾아줘.
내용은 복사하지 말고 규칙만 추출해 기존 주보에세이 레시피의 변경안을 보여줘.
```

예시는 **어떻게 만들지**를 알려주고, 완성설교는 **무엇을 말할지**를 결정합니다. 둘이 충돌하면 완성설교와 사용자의 이번 요청을 우선합니다.
