# 안전과 출처 확인

## 설교자가 확인할 것

- 성경 구절의 번역과 문맥
- 원어·역사·문화 배경 설명
- 책·강연·인터뷰의 정확한 인용과 페이지 또는 시간
- 실제 인물과 사건을 사용한 예화의 사실 여부
- 교단과 교회의 신학적 기준
- 개인 정보, 상담 내용, 실명 사례의 노출 여부

## AI가 지켜야 할 표시

- 확실한 원본이 있으면 원본 노트 링크를 남긴다.
- 추론은 사실처럼 단정하지 않고 `해석 제안` 또는 `확인 필요`로 표시한다.
- 출처 없는 직접 인용은 만들지 않는다.
- 개인·상담 사례는 익명화하고 불필요한 세부 정보를 삭제한다.
- 외부 검색 자료를 사용할 경우 URL과 확인 날짜를 남긴다.

## 발행 전 체크

- [ ] 핵심 메시지가 완성설교와 일치한다.
- [ ] 성경 인용을 대조했다.
- [ ] 직접 인용의 출처를 확인했다.
- [ ] 저작권상 과도한 인용이 없다.
- [ ] 개인정보와 민감한 목회 사례가 안전하다.
- [ ] AI가 새로 보탠 주장을 구분하고 검토했다.
