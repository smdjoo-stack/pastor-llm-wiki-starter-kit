# 2단계 확장 안내

1단계는 설교 중심으로 단순하게 운영합니다. 구조가 안정되고 설교위키에 지식이 충분히 쌓인 뒤, 필요할 때만 `40. 목회자료`를 추가합니다.

```text
40. 목회자료/
├── 제자훈련/
├── 성경공부/
├── 리더교육/
├── 목회상담/
├── 심방/
└── 선교/
```

`20. 설교위키`는 재사용 가능한 **지식**, `40. 목회자료`는 그 지식을 특정 목회 현장에 적용한 **독립 사역자료**, `70. 설교활용`은 특정 완성설교의 **파생 콘텐츠**입니다.

다음과 같은 필요가 반복될 때 2단계를 제안합니다.

- 여러 설교의 지식을 묶어 4주 제자훈련을 만들고 싶다.
- 상담·심방·리더교육 자료를 계속 재사용하고 싶다.
- 특정 설교 한 편의 파생물이 아닌 독립적인 사역자료가 늘어난다.

처음부터 이 폴더를 추가하지 않는 이유는 설교 중심 흐름을 먼저 익히고, 검색 결과에 중복 자료가 쌓이는 것을 막기 위해서입니다.
