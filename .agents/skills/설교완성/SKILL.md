# 설교완성

## 실행 전 필수로 읽기

1. `AGENTS.md`
2. `90. 설정/명령어/설교완성.md` — 이 작업의 상세 실행 절차와 완료 조건

위 두 문서의 규칙을 그대로 따른다. 어떤 파일이 목회자가 확정한 최종본인지 먼저 확인하고, 1차설교와 연결자료를 임의로 합치지 않는다.

## 완료 후

- `90. 설정/명령어/설교완성.md`의 "완료 조건"을 모두 충족했는지 확인하고 사용자에게 보고한다.
- `log.md` 맨 위에 새 항목을 추가한다: `## [YYYY-MM-DD] /설교완성 | {설교 제목}`
- `index.md`의 통계·설교 흐름·MOC 목록을 갱신하고, `90. 설정/대시보드.html`의 `DATA`도 같은 값으로 갱신한다.
