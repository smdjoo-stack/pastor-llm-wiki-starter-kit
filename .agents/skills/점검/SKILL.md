# 점검

## 실행 전 필수로 읽기

1. `AGENTS.md`
2. `90. 설정/명령어/점검.md` — 이 작업의 상세 점검 항목
3. `90. 설정/사용안내/06. 월간 점검표.md` — 점검 체크리스트 원본

위 문서의 규칙을 그대로 따른다. **사용자가 명시적으로 "고쳐줘"라고 하지 않는 한 파일을 수정하지 않는다.**

## 완료 후

중요도순 목록으로 보고한다. 사용자가 수정을 승인한 항목만 고치고, 고친 경우 `log.md`에 기록한다.
