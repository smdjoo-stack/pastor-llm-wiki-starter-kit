# 수집

## 실행 전 필수로 읽기

1. `AGENTS.md`
2. `90. 설정/명령어/수집.md` — 이 작업의 상세 실행 절차

위 두 문서의 규칙을 그대로 따른다.

## 대상

사용자가 대상을 명시하면 그것을, 명시하지 않으면 `00. 수집함`의 하위 폴더(기사와자료/떠오른생각/블로그/유튜브/책)를 훑어보고 처리할 파일을 사용자에게 확인한다.

## 완료 후

- `90. 설정/명령어/수집.md`의 "완료 보고" 항목대로 사용자에게 요약한다.
- `log.md` 맨 위에 새 항목을 추가한다: `## [YYYY-MM-DD] /수집 | {자료 제목}`
- `index.md`와 `90. 설정/대시보드.html`의 `DATA`를 같은 값으로 갱신한다.
