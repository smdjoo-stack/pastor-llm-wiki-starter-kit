# 위키

## 실행 전 필수로 읽기

1. `AGENTS.md`
2. `90. 설정/명령어/위키.md` — **대상 규칙**
3. `90. 설정/명령어/수집.md` — **공통 실행 절차** (「실행」~「완료 보고」)

## 대상

사용자가 지정한 폴더나 파일. **대상이 없으면 실행하지 않는다** — `수집`(수집함 전체)을 쓸지, 아니면 대상을 지정할지 사용자에게 묻는다.

받을 수 있는 대상: 파일 하나 · 폴더 · 조건(`상태: 미처리`인 것 전부 등) · 수집함 안의 일부.

## 핵심

- **하는 일은 `수집`과 같다** — 원본자료로 보존하고 설교위키를 만든다. 다른 것은 대상 지정 방식뿐이다.
- **대상이 이미 `10. 원본자료`에 있으면 옮기지 않는다** — 프론트매터를 채우고, 위키를 만들고, `상태: 미처리` → `처리완료`로 바꾼다. 단 폴더가 잘못되었으면 옮기고 이유를 원본 노트에 적는다.
- **처리하지 않고 남긴 것을 완료 보고에 밝힌다.**

## 완료 후

- `90. 설정/명령어/수집.md`의 "완료 보고" 항목대로 표로 요약한다 — 저자 판정 근거와 폴더 이동 이유 포함.
- `log.md` 맨 위에 `## [YYYY-MM-DD] /위키 | {자료 제목}` 항목을 추가한다.
- `index.md`와 `90. 설정/대시보드.html`의 `DATA`를 같은 값으로 갱신한다.
