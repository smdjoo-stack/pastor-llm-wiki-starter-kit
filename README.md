# 목회자 LLM-Wiki 스타트킷 v1.3.0

> 수집 → 원본 보존 → Wiki 재사용 → MOC 연결 → 설교 → 활용

릴리스 v1.3.0 · 1단계(설교 중심) 범위. 변경 내역은 [버전.md](버전.md)를 보십시오.

이 볼트는 목회자가 지금까지 설교하고, 읽고, 보고, 생각한 것을 축적하여 새 설교를 돕고, 완성된 설교를 다양한 목회 콘텐츠로 활용하기 위한 개인 지식 시스템입니다.

## 처음 시작하기

1. 이 폴더를 Obsidian에서 **볼트로 열기** 합니다.
2. AI가 이 폴더의 Markdown 파일을 읽고 쓸 수 있게 연결합니다.
3. `90. 설정/사용안내/01. 10분 시작하기.md`를 엽니다.
4. 새 자료는 `00. 수집함`에 넣고 AI에게 `/수집`이라고 요청합니다.
5. 기존 설교나 강의·성경공부 같은 과거 자료는 `10. 원본자료/기존자료`에 넣고 `/등록`을 요청합니다.

## 핵심 원칙

- **원본 보존:** 원문은 수정하거나 덮어쓰지 않습니다.
- **Wiki 재사용:** 한 자료를 통째로 요약하는 대신 다시 쓸 수 있는 작은 지식으로 나눕니다.
- **Query 중심:** AI는 폴더를 무작정 전부 요약하지 않고, 지금의 설교 질문에 답하기 위해 검색합니다.
- **MOC 중심 연결:** MOC는 관련 본문·주제·인물·신학·설교·통찰을 묶는 설교 연구 지도입니다.
- **사람이 결정:** AI는 연결자료를 제안하고, 설교자가 선택하고 판단합니다.
- **입력과 출력 분리:** 설교 활용 결과물은 다시 Wiki에 넣지 않아 중복을 막습니다.

## 핵심 명령

| 명령 | 하는 일 |
|---|---|
| `/수집` | 새 자료의 원본을 보존하고 재사용 지식을 추출하여 MOC에 연결 |
| `/등록` | 과거에 완성한 자료(설교/강의/성경공부 등)를 원본으로 등록하고 Wiki와 MOC를 갱신 |
| `/주석` | 성경 본문 AI 리서치를 설교준비 참고자료로 만듦 (Wiki 추출 안 함) |
| `/주석설정` | `/주석`의 리서치 깊이·범위 레시피 조정 |
| `/설교연결` | 1차 설교를 분석하고 관련 지식을 찾아 별도 연결자료 생성 |
| `/설교완성` | 확정한 설교를 완성설교로 보존하고 Wiki와 MOC를 갱신 |
| `/활용` | 완성설교를 소그룹·주보·카드뉴스·숏츠·SNS 콘텐츠로 변환 |
| `/활용설정` | 우리 교회의 문체와 형식에 맞게 출력 레시피를 조정 |
| `/상태` | 볼트 현황 스냅샷 (읽기 전용) |
| `/점검` | 월간 점검표 항목 자동 점검 (기본 읽기 전용) |

명령은 프로그램 버튼이 아니라 **AI에게 주는 약속된 요청어**입니다. 자세한 실행 규칙은 `90. 설정/명령어`에 있습니다.

## 폴더 지도

```text
00. 수집함       일단 넣어두는 곳
10. 원본자료     원래 자료를 보존하는 곳
20. 설교위키     다시 사용할 작은 지식
  29. MOC        지식을 묶은 설교 연구 지도
30. 설교준비     1차설교 → 연결자료 → 완성설교
70. 설교활용     완성설교에서 만든 파생 콘텐츠
80. 참고자료     이미지·PDF 등 첨부파일
90. 설정         템플릿·명령어·출력 레시피·사용안내
```

## 권장 파일 이름

- 원본자료: `2026-09-13 자료 제목.md`
- 기존자료: `2026-09-13 제목.md` (자료유형은 프론트매터로 구분: 설교/강의/성경공부/교육자료/기타)
- Wiki: 한 노트에 한 개념, 예: `두려움과 통제.md`
- MOC: `두려움 MOC.md`
- 연결자료: `2026-09-13 설교 제목 - 연결자료.md`
- 활용 결과: `2026-09-13 설교 제목 - 주보에세이.md`

## 주의

AI가 만든 성경 인용, 책 인용, 사실 정보는 반드시 원본과 대조하십시오. 출처를 확인할 수 없는 직접 인용은 사용하지 않는 것을 기본으로 합니다.
