# 질문 안내

이곳은 `/질문`으로 만든 질문-답변 기록입니다. 특정 설교 준비와 무관하게, 지금 쌓인 설교위키가 어떤 주제에 대해 무엇을 갖고 있는지 바로 확인하고 싶을 때 씁니다.

- `30. 설교준비/연결자료`와 다릅니다: 연결자료는 특정 1차설교에 종속되지만, 질문 결과는 독립적인 탐색 기록입니다.
- 답변은 기존 Wiki·MOC·주석에서 찾은 근거로만 구성됩니다. 근거가 없으면 "확인 필요"로 남깁니다.
- 답변 과정에서 Wiki 노트 사이의 모순을 발견하면, 새 노트를 만드는 대신 해당 노트에 `> [!warning] 상충하는 정보` 콜아웃만 추가합니다.
