# 수집함 안내

분류에 오래 고민하지 말고 새 자료를 가장 가까운 폴더에 넣습니다.

- 책: 독서 메모, 발췌, 서지 정보
- 유튜브: 링크, 자막, 시간 표시 메모
- 블로그: URL과 발췌 또는 저장한 글
- 기사와자료: 기사, 논문, 세미나, 보고서
- 떠오른생각: 짧은 묵상, 질문, 설교 씨앗
- 기존자료: 예전에 만든 설교·강의·성경공부·교육자료 원고 (이 폴더에 넣으면 `/수집`이 아니라 `/등록`이 처리합니다)

팟캐스트·강연·SNS처럼 폴더에 없는 자료는 폴더를 새로 만들지 말고 가장 가까운 곳(팟캐스트·강연 → `유튜브`, SNS → `블로그`)에 넣은 뒤 원본자료의 `자료유형` 값으로 구분합니다 — `00. 수집함`과 `10. 원본자료`의 하위 분류명이 항상 같아야 하므로 폴더는 6개로 고정합니다.

가능하면 제목, 저자, URL, 페이지 또는 영상 시간을 함께 적습니다. 처리 후 `/수집`(기존자료는 `/등록`)은 원본을 `10. 원본자료`의 같은 이름 폴더에 보존합니다 — 두 폴더의 하위 분류명은 항상 같아야 합니다.

성경 본문 AI 리서치는 이 수집함을 거치지 않습니다 — `/주석`으로 바로 `30. 설교준비/주석`에 만듭니다 (Wiki로 쪼개지 않습니다).
